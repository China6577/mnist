# 用 PyTorch 和简单 CNN 识别 MNIST 手写数字

这是一个面向初学者的完整小项目。目标不只是得到较高准确率，还要理解一张图片怎样经过 CNN，模型又怎样通过错误不断修改自己。

本项目已经在本机实际训练和调参。最终配置训练 5 轮后：

- 验证集准确率：**98.87%**
- 测试集准确率：**99.07%**
- 最佳模型：`outputs/best_model.pth`
- 学习曲线：`outputs/learning_curves.png`

> 准确率会受硬件、PyTorch 版本和随机计算细节影响，重新训练时有很小差异是正常的。

## 2. 什么是 MNIST

MNIST 是经典的手写数字数据集：

- 每张图片是 `28 × 28` 像素；
- 图片是灰度图，所以只有 1 个颜色通道；
- 标签为 0～9，共 10 个类别；
- 官方训练集有 60,000 张，官方测试集有 10,000 张。

项目把 60,000 张官方训练图片进一步固定拆成：

- 54,000 张训练集：真正用于更新网络参数；
- 6,000 张验证集：用于比较参数、选择最佳训练轮次；
- 10,000 张测试集：参数全部确定后，只用于最终考试。

不能一边看测试集成绩一边调参数。那相当于做题时偷看最终考试答案，会使测试准确率失去公正性。

## 3. 使用了什么算法

### 3.1 核心算法：卷积神经网络 CNN

CNN（Convolutional Neural Network，卷积神经网络）特别适合图片。

普通全连接网络会把 `28 × 28` 图片直接摊成 784 个数字，因此不容易利用像素的上下左右关系。CNN 使用小卷积核在整张图片上滑动，同一个卷积核在每个位置重复使用，可以学习横线、竖线、边缘、圆弧等局部特征。

选择 CNN 的原因：

1. **保留空间关系**：相邻像素一起参与卷积，符合图片结构。
2. **参数共享**：同一个卷积核检查整张图，参数比全连接方式少。
3. **逐层组合特征**：第一层找到线条，第二层可以把线条组合成圆弧、拐角和局部数字形状。
4. **对小范围移动更稳定**：数字稍微偏一点，卷积和池化仍能找到类似特征。

### 3.2 损失函数：交叉熵损失

模型输出 10 个原始分数，正确类别的分数应该最高。`CrossEntropyLoss` 会把这些分数转化为可比较的概率关系，并衡量预测与正确标签之间的差距。

预测越错，损失通常越大；预测越正确且越有把握，损失越小。训练的目标就是让损失不断下降。

代码最后一层后面没有手动添加 Softmax，因为 `CrossEntropyLoss` 已在内部用数值更稳定的方式完成了对应运算。只有在 `predict.py` 中向人展示概率时，才显式使用 `softmax`。

### 3.3 优化器：Adam

反向传播先计算“每个参数应该朝哪个方向改变”，Adam 再真正更新参数。Adam 会根据每个参数近期的梯度自动调节更新幅度，通常收敛快、对初始学习率不太敏感，很适合第一个 CNN 项目。

这里使用学习率 `0.001`：

- 太小会学得慢；
- 太大会在较优参数两边来回跳，甚至无法收敛；
- `0.001` 在实际对比中速度和稳定性都较好，也是 Adam 常用起点。

### 3.4 训练是怎样发生的

对每一批图片都重复下面四步：

1. **前向传播**：图片经过 CNN，得到 0～9 的 10 个分数。
2. **计算损失**：比较预测分数和正确标签。
3. **反向传播**：`loss.backward()` 用链式法则自动计算所有参数的梯度。
4. **更新参数**：`optimizer.step()` 让 Adam 修改权重和偏置。

一个 Epoch 表示模型完整看过一遍训练集。这里训练 5 个 Epoch，即完整学习 5 遍。

## 4. 网络每一层有什么，尺寸怎样变化

整个数据流如下：

```text
输入图片 [N, 1, 28, 28]
    ↓ Conv2d(1 → 16, 3×3, padding=1) + ReLU
特征图 [N, 16, 28, 28]
    ↓ MaxPool2d(2×2)
特征图 [N, 16, 14, 14]
    ↓ Conv2d(16 → 32, 3×3, padding=1) + ReLU
特征图 [N, 32, 14, 14]
    ↓ MaxPool2d(2×2)
特征图 [N, 32, 7, 7]
    ↓ Flatten
向量 [N, 1568]
    ↓ Linear(1568 → 128) + ReLU + Dropout(0.25)
向量 [N, 128]
    ↓ Linear(128 → 10)
输出分数 [N, 10]
```

`N` 是一批图片的数量。默认 `batch_size=128`，大部分批次中 N 就是 128。

| 层 | 设置 | 输出尺寸（省略 N） | 作用和设置理由 |
|---|---|---:|---|
| 输入 | 1 通道灰度图 | `1×28×28` | MNIST 本身就是 28×28 灰度图片 |
| 卷积 1 | `1→16`，`3×3`，padding=1 | `16×28×28` | 16 个卷积核足以学习基本边缘；3×3 小而常用；补 1 圈 0 保持宽高 |
| ReLU | 小于 0 的值变为 0 | 不变 | 加入非线性，否则多层线性运算仍近似一层线性运算 |
| 最大池化 1 | `2×2`，步长 2 | `16×14×14` | 宽高减半，减少计算并保留最明显的局部特征 |
| 卷积 2 | `16→32`，`3×3`，padding=1 | `32×14×14` | 用更多通道把简单边缘组合成更复杂形状 |
| ReLU | 同上 | 不变 | 再次加入非线性能力 |
| 最大池化 2 | `2×2`，步长 2 | `32×7×7` | 再次压缩，得到紧凑的高层特征 |
| Flatten | 展平 | `1568` | `32×7×7=1568`，转换成全连接层需要的向量 |
| 全连接 1 | `1568→128` | `128` | 综合图片各位置的特征；128 在表达能力和简单程度之间平衡 |
| Dropout | `p=0.25` | `128` | 训练时随机关闭 25% 特征，减少死记硬背 |
| 全连接 2 | `128→10` | `10` | 每个输出对应一个数字类别 |

### 4.1 到底算几层

“层数”有不同口径。通常只数带可训练参数的层，本网络是：

- 2 个卷积层；
- 2 个全连接层；
- 合计 4 个可训练层。

ReLU、池化、Flatten 和 Dropout 也是网络操作，但它们没有需要梯度下降学习的权重，一般不计入“4 层”。

### 4.2 为什么只用两个卷积层

MNIST 图片只有 28×28，而且图案只是相对简单的单个数字。两个卷积层已经能完成“像素 → 边缘 → 局部形状”的特征层次。最终实测达到 99.07%，说明容量已经足够。

继续堆很深的网络会增加代码理解难度、训练时间和过拟合可能，对这个学习项目收益很小。若以后处理猫狗照片等复杂彩色图片，才更需要更深的网络。

### 4.3 网络有多少个可训练参数

本网络一共有 **206,922** 个可训练参数：

```text
卷积 1：16 × (1×3×3 + 1个偏置)       =     160
卷积 2：32 × (16×3×3 + 1个偏置)      =   4,640
全连接 1：1568×128 + 128个偏置        = 200,832
全连接 2：128×10 + 10个偏置           =   1,290
合计                                    206,922
```

“学习”本质上就是用训练数据找到这 206,922 个参数的合适数值。

## 5. 数据预处理为什么这样做

`ToTensor()` 完成两件事：把图片变成 PyTorch 张量，并把像素从 0～255 缩放到 0～1。

`Normalize((0.1307,), (0.3081,))` 再按照 MNIST 的均值和标准差处理像素：

```text
标准化后的像素 = (原像素 - 0.1307) / 0.3081
```

这样能让输入的数值尺度更适合梯度优化，训练一般更稳定。训练、测试和自己的图片必须使用相同的标准化，否则模型看到的数据分布不一致。

本项目没有加入旋转、平移等数据增强，因为重点是让第一版代码简单清楚。等掌握基本流程后，可以把轻微旋转和平移作为练习。

## 6. 参数调整过程和依据

所有对比都使用相同随机种子、相同训练/验证划分、批量大小 128，并只训练 3 轮。调参期间设置了 `--skip-test`，没有查看测试集。

| 实验 | 学习率 | Dropout | 第 3 轮验证准确率 | 结论 |
|---|---:|---:|---:|---|
| 较小学习率 | 0.0003 | 0.25 | 98.03% | 稳定，但学习偏慢 |
| 标准配置 | 0.001 | 0.25 | **98.68%** | 快且稳定，选用 |
| 较大学习率 | 0.003 | 0.25 | 98.68% | 同样较高，但更新更激进 |
| 更强 Dropout | 0.001 | 0.50 | 98.57% | 正则化略强，学习变慢 |

最终选择：

```text
优化器        Adam
学习率        0.001
批量大小      128
Dropout       0.25
训练轮数      5
随机种子      42
```

为什么训练 5 轮：第 3～5 轮验证准确率从 98.73% → 98.77% → 98.87%，仍在小幅提升；5 轮已能得到很好结果，也不会让初学练习等待太久。代码每轮都会保存验证集最好的模型，所以即使以后增加轮数，也不会只保留可能已经过拟合的最后一轮。

最终 5 轮实际结果：

| Epoch | 训练损失 | 训练准确率 | 验证损失 | 验证准确率 |
|---:|---:|---:|---:|---:|
| 1 | 0.2624 | 92.05% | 0.0859 | 97.43% |
| 2 | 0.0729 | 97.76% | 0.0593 | 98.20% |
| 3 | 0.0519 | 98.42% | 0.0472 | 98.73% |
| 4 | 0.0404 | 98.71% | 0.0439 | 98.77% |
| 5 | 0.0341 | 98.94% | 0.0413 | 98.87% |

训练损失和验证损失都在下降，两个准确率都在提升，且差距很小，因此没有明显过拟合。最佳模型在测试集的损失是 0.0296，准确率是 99.07%。

## 7. 从零运行

### 7.1 安装依赖

在本目录打开终端，然后运行：

```bash
conda activate ai-common

```

如果已经创建了 `ai-common`，这些依赖已经安装完成，可直接运行项目。

如果电脑有支持 CUDA 的 NVIDIA 显卡，建议根据 [PyTorch 官方安装选择器](https://pytorch.org/get-started/locally/) 安装对应 CUDA 版本。本项目会自动使用可用的 NVIDIA GPU，否则自动使用 CPU，代码无需修改。

### 7.2 检查网络形状

```bash
python model.py
```

正确输出应包含：

```text
输入形状: (4, 1, 28, 28)
输出形状: (4, 10)
```

意思是输入 4 张灰度图片，模型为每张图片输出 10 个类别分数。

### 7.3 训练

直接使用已经调好的默认参数：

```bash
python train.py
```

第一次运行会自动下载 MNIST。训练完成后，模型和训练曲线会出现在 `outputs` 文件夹。

也可以自行实验：

```bash
python train.py --epochs 8 --batch-size 64 --learning-rate 0.0005 --dropout 0.3
```

一次只改变一个参数，才能知道结果变化由谁造成。

### 7.4 识别自己的图片

准备一张只包含一个数字的图片，例如 `my_digit.png`，然后运行：

```bash
python predict.py my_digit.png
```

程序会输出预测数字、最高置信度以及 0～9 的全部概率。自己的图片最好满足：

- 一个画面只写一个数字；
- 数字尽量居中并占据画面大部分区域；
- 背景干净，数字与背景对比明显；
- 不要画得太细或裁掉笔画。

程序会自动判断常见的白底黑字图片并反色，但手机照片与 MNIST 风格差异较大，所以识别效果可能低于测试集准确率。

### 7.5 打开手写识别网页

运行本地网页服务：

```bash
python web_app.py
```

在 Windows 中也可以直接双击 `start_web.bat`。启动后的终端窗口需要保持打开；关闭窗口就会停止网页服务。

在浏览器打开：

```text
http://127.0.0.1:5000
```

按住鼠标或用触屏在黑色画布上写一个数字，再点击“开始识别”。页面会显示预测数字、置信度和 0～9 的全部概率。“清空重写”可以开始下一次尝试。

## 8. 读懂训练代码的五个关键位置

初读 `train.py` 时，先找到这些语句：

```python
logits = model(images)               # 1. 前向传播
loss = loss_function(logits, labels) # 2. 计算错误程度
optimizer.zero_grad()                # 清除上一批梯度
loss.backward()                      # 3. 反向传播，计算梯度
optimizer.step()                     # 4. 更新参数
```

训练代码的其他部分主要是在准备数据、统计准确率、保存结果。真正让模型学习的核心就是上面几行。

## 9. 初学者常见问题

### 为什么训练时不直接统计 Softmax 概率？

选最大类别只需要比较 10 个原始分数，Softmax 不会改变它们的大小顺序。损失函数内部也已经处理了概率关系，因此训练时无需重复计算。

### `model.train()` 和 `model.eval()` 有什么区别？

它们不是“开始训练”和“开始测试”的完整命令，而是切换层的行为。本项目中最重要的区别是：训练模式启用 Dropout，评价模式关闭 Dropout。评价时还使用 `torch.no_grad()`，因为不需要反向传播，可以节省内存和时间。

### Batch Size 为什么是 128？

一次只用 1 张图片更新，梯度波动较大且硬件利用率低；一次使用全部图片又很占显存。128 是这个小模型中速度、显存和梯度稳定性的合理平衡。它不是唯一正确答案，64 或 256 通常也能训练。

### 准确率 99% 是否表示任何手写数字都能识别？

不是。99.07% 指模型在与 MNIST 风格相同的测试集上的结果。拍照光线、背景、数字位置和书写风格改变后，数据分布也改变，准确率可能下降。

## 10. 掌握以后可以做的练习

1. 把卷积通道从 `16、32` 改为 `32、64`，观察参数量、速度和准确率。
2. 比较 SGD 和 Adam，需要注意 SGD 通常要重新调学习率。
3. 加入轻微旋转和平移的数据增强，测试自己的图片是否更容易识别。
4. 画出混淆矩阵，观察 4 和 9、3 和 5 等哪些数字容易混淆。
5. 显示第一层卷积后的特征图，直观看网络找到了哪些边缘。

每次实验请记录“只改了什么、验证结果怎样”，这比盲目堆更复杂的网络更能帮助理解深度学习。
